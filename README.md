Portfolio personal construido con Astro, TypeScript y Tailwind CSS. Un sitio web moderno y rápido para mostrar mis proyectos y habilidades como desarrollador.

## 🚀 Características

- ⚡️ Velocidad ultra rápida con Astro
- 🎨 Diseño responsive con Tailwind CSS
- 📝 TypeScript para mayor seguridad en el código
- 🎯 SEO optimizado
- 🌙 Interfaz moderna y limpia

## 🛠️ Tecnologías

- **Framework:** [Astro](https://astro.build) v5.14.5
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/) v5.5.4
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) v3.4.10
- **Fuente:** JetBrains Mono Variable
- **Linting:** ESLint + Prettier

## 📋 Requisitos previos

- Node.js 18+ o superior
- pnpm (recomendado) o npm

## 🔧 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/fahoyosCode/fahoyos.dev.git
cd fahoyos.dev
```

2. Instala las dependencias:
```bash
pnpm install
# o
npm install
```

## 🚀 Uso

### Desarrollo
Inicia el servidor de desarrollo:
```bash
pnpm dev
# o
npm run dev
```
El sitio estará disponible en `http://localhost:4321`

### Build
Genera la versión de producción:
```bash
pnpm build
# o
npm run build
```

### Preview
Previsualiza la build de producción:
```bash
pnpm preview
# o
npm run preview
```

## 📁 Estructura del proyecto
